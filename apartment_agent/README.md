# Apartment Rental Agent

This sample project demonstrates a simple FastAPI backend that uses an AI-powered agent to send rent reminders and stores data in Google Sheets.

## Features

- Add apartments and bookings via REST API.
- Persist data in Google Sheets using a service account.
- Daily scheduled task checks for bookings that end within a month and sends reminder emails.
- Reminder email body is generated by OpenAI's chat completion API.

## Configuration

Create a `.env` file or set environment variables:

```
GOOGLE_APPLICATION_CREDENTIALS=path/to/service_account.json
SPREADSHEET_ID=your_spreadsheet_id
EMAIL_HOST=smtp.example.com
EMAIL_PORT=587
EMAIL_USER=user@example.com
EMAIL_PASS=your_password
OPENAI_API_KEY=sk-...
```

Your spreadsheet requires two worksheets named **Apartments** and **Bookings** with appropriate columns.

## Running

Install dependencies and start the server:

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

Use any scheduler to run `python app.py` to enable daily reminders.
